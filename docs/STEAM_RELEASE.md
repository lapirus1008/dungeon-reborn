# 스팀 출시 안내서

게임 쪽 준비(스팀용 빌드, 스팀 계정 로그인, 설정 창, 라이선스 파일)는 끝나 있습니다.
아래는 **직접 하셔야 하는 일**(돈·계정·서류가 필요한 일)과, 그 다음에 실행할 명령입니다.

---

## 1. 스팀웍스 가입과 앱 만들기 (직접)

1. https://partner.steamgames.com 에서 스팀웍스(개발사) 가입
2. 회사/개인 정보, **세금 정보**(한국 개인이면 W-8BEN), **은행 계좌** 입력
3. **Steam Direct 수수료 100달러** 결제 → 앱 1개 생성 권한
4. 앱이 만들어지면 **앱 ID**(예: `1234560`)가 생김
   - 윈도우용 **디포 ID**는 보통 앱 ID + 1 (예: `1234561`)
   - Steamworks > 앱 관리 > SteamPipe > 디포 에서 확인

> 수수료를 내고 앱을 처음 만든 뒤 **30일이 지나야** 출시할 수 있고, 스토어 페이지는 출시 **2주 전**부터 "출시 예정"으로 공개돼 있어야 합니다.

## 2. (선택) 스팀 연동 플러그인 넣기 — 스팀 닉네임 · 스팀 계정 로그인 · 오버레이

플러그인이 없어도 게임은 스팀에서 실행되고 이름 + PIN으로 온라인에 접속합니다.
넣으면 **스팀 계정으로 바로 로그인**(PIN 없음)과 스팀 오버레이(Shift+Tab)가 됩니다.

1. Godot 에디터로 `godot/` 프로젝트를 엶
2. 위쪽 **AssetLib** 탭 → `GodotSteam` 검색 → **GodotSteam GDExtension 4.x** (Godot 4.5용) 설치
   - 또는 https://github.com/GodotSteam/GodotSteam/releases 에서 GDExtension 판 zip을 받아 `godot/addons/godotsteam/` 에 풀기
3. `godot/addons/godotsteam/` 폴더를 저장소에 올리기 (그러면 빌드할 때 `steam_api64.dll` 등이 자동으로 함께 들어감)
4. 확인: 스팀에서 게임을 켜면 로비 '함께하기' 탭에 **🎮 스팀 계정으로 온라인 접속** 버튼이 보임

코드는 플러그인이 있는지 스스로 확인합니다(`godot/scripts/steam_glue.gd`). 따로 고칠 것은 없습니다.

## 3. 서버에 스팀 로그인 켜기 (직접, 1회)

스팀 계정 로그인은 **서버가 스팀에 직접 확인**합니다(가짜 로그인 방지). 서버에 키를 넣어야 합니다.

1. Steamworks > 사용자 및 권한 > **그룹 관리** > 내 그룹 > **웹 API 키 만들기** (퍼블리셔 키)
2. 서버(Lightsail)에서 `~/dungeon-reborn/server/.env` 파일을 만들고:
   ```
   STEAM_WEBAPI_KEY=여기에_키
   STEAM_APP_ID=1234560
   ```
   - 이 파일은 저장소에 올라가지 않게 막혀 있습니다(`.gitignore`). **키를 절대 공개하지 마세요.**
3. 서버 다시 시작:
   ```
   cd ~/dungeon-reborn && git pull && docker compose -f server/docker-compose.yml up -d --build
   ```
키가 없는 서버는 스팀 로그인을 "이 서버는 스팀 로그인이 설정되지 않았습니다"라고 거절하고, 이름 + PIN 로그인은 그대로 됩니다.

## 4. 스팀용 빌드 만들고 올리기

### 빌드 (이 저장소에서)
```
GODOT=/경로/Godot_v4.5.1-stable 실행 파일 tools/steam/build_steam.sh
```
결과: `tools/steam/content/windows/`
- `DungeonReborn.exe` (이름·버전·아이콘이 들어간 실행 파일)
- `DungeonReborn.pck` (모든 그림·모델·소리, 약 130MB)
- `licenses/` (글꼴·에셋·엔진 라이선스와 만든 이)
- 플러그인을 넣었다면 `steam_api64.dll` 등

GitHub 업로드 제한 때문에 나눴던 zip 3개와 달리, 스팀은 이 폴더 하나를 그대로 올립니다.
빌드를 매번 직접 하기 어려우면 저에게 "스팀 빌드 만들어줘"라고 하시면 `apk` 브랜치처럼 올려 드릴 수 있습니다.

### 업로드 (SteamCMD)
1. SteamCMD 설치: https://developer.valvesoftware.com/wiki/SteamCMD
2. ```
   STEAM_APP_ID=1234560 STEAM_DEPOT_ID=1234561 STEAM_USER=스팀웍스계정 tools/steam/upload_steam.sh "첫 빌드"
   ```
   처음엔 스팀 가드 코드를 물어봅니다.
3. Steamworks > SteamPipe > **빌드** 에서 방금 올린 빌드를 **default 브랜치에 설정** → 게시

### 스팀웍스에서 실행 옵션 설정 (1회)
Steamworks > 설치 > 일반 > **실행 옵션** 추가
- 실행 파일: `DungeonReborn.exe`
- 운영체제: Windows, 64비트
- 설치 폴더 이름: `Dungeon Reborn`

## 5. 스토어 페이지 준비물 (직접)

| 항목 | 크기/수량 |
|---|---|
| 헤더 캡슐 | 920 × 430 |
| 작은 캡슐 | 462 × 174 |
| 메인 캡슐 | 1232 × 706 |
| 세로 캡슐 | 748 × 896 |
| 라이브러리 캡슐 / 영웅 / 로고 | 600 × 900, 3840 × 1240, 1280 × 720(투명 PNG) |
| 스크린샷 | 1920 × 1080 이상, 5장 이상 (게임 화면만) |
| 트레일러 | 권장 (선택) |
| 설명 | 짧은 설명(300자), 긴 설명, 태그(익스트랙션, 던전 크롤러, PvPvE, 1인칭 등) |

권장 시스템 요구 사항(예시): Windows 10 64비트, 4코어 CPU, 8GB RAM, GTX 1060급 그래픽(Vulkan 지원), 저장 공간 1GB.

## 6. 출시 전 확인

- [ ] 스팀에서 설치해 켜기 → 전체 화면, 설정 창(화면·소리·조작·키), 게임 종료 버튼 확인
- [ ] 온라인 접속 (스팀 계정 / 이름 + PIN) → 레이드 → 탈출 → 장비가 서버 계정에 저장되는지
- [ ] 서버와 게임 빌드 번호가 같은지 (다르면 "게임 버전이 다릅니다" 안내가 나오고 접속이 막힘)
  → **게임을 업데이트할 때마다 서버도 같은 커밋으로 업데이트**해야 합니다
- [ ] 빌드 검수 제출: 스팀이 실제로 실행해 보고 며칠 안에 통과 여부를 알려 줌

## 7. 온라인 서버 운영 메모

- 지금 서버: AWS Lightsail 한 대, 동시 접속 100명까지 (서버가 가득 차면 안내 후 거절)
- 계정은 `server/data/accounts/` 에 저장 → **정기 백업** 권장 (Lightsail 스냅샷)
- 서버 주소가 IP로 박혀 있음(`Net.OFFICIAL_SERVER`). 출시 전에 도메인(예: play.내도메인.com)을 사서 연결하면 서버를 옮겨도 게임을 다시 올리지 않아도 됩니다 — 도메인이 정해지면 알려 주세요
- 서버 보안: 통신 암호화(DTLS), 요청 폭주 차단, 이동 속도 검증, 로그인 실패 잠금은 이미 들어 있음 (`SECURITY.md`)
