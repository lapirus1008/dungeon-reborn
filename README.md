# Dungeon Reborn 실행 파일 (APK / Windows)

게임 빌드: `20261013-160950` (온라인 서버도 같은 빌드여야 접속됨)

## 안드로이드
- 파일: `DungeonReborn.apk` (arm64, 갤럭시 S21 기준, 앱 버전 0.6)
- 받기: https://github.com/lapirus1008/dungeon-reborn/raw/apk/DungeonReborn.apk (폰은 크롬 권장)
- 설치: "출처를 알 수 없는 앱" 허용, Play 프로텍트 경고는 "무시하고 설치"

## Windows (PC)
- 파일: `DungeonReborn-windows.zip` (압축을 풀면 `DungeonReborn.exe` 하나, Godot 4.5.1로 내보냄)
- 받기: https://github.com/lapirus1008/dungeon-reborn/raw/apk/DungeonReborn-windows.zip
- 실행: 압축 해제 후 `DungeonReborn.exe` 실행. "Windows의 PC 보호" 창이 뜨면 "추가 정보 → 실행"
- exe가 155MB라 GitHub 파일 한도(100MB) 때문에 zip으로 올림
