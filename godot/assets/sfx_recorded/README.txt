녹음된 효과음을 넣는 곳 (docs/ASSETS_STAGE3.md 참고)

파일 이름 = 게임 속 소리 이름. 같은 소리를 여러 개 넣으면 무작위로 골라 재생합니다.
  예) step.ogg, step_2.ogg, step_3.ogg  → 발소리 3가지
지원 형식: wav, ogg, mp3
여기 있는 소리가 assets/sfx(합성 소리)보다 우선합니다. 없는 이름은 기존 소리를 그대로 씁니다.

소리 이름 목록:
step swing hit block shield_hit bow draw_blade draw_wood draw_soft pickup drop coin
chest door door_shut fire growl hurt death magic heal shield shield_break portal bell
ui bandage potion_open rummage
